# Library Management System

Лабораторна робота №2 з дисципліни «Вебсистеми».

## Тема

Розробка клієнтського застосунку управління бібліотекою.

## Мета

Створити вебзастосунок для обліку книг і користувачів, позичання та повернення книг із використанням TypeScript, класів, інтерфейсів, generics, модулів і просторів імен.

## Технології

- TypeScript
- Webpack
- Bootstrap
- LocalStorage
- Mocha
- Chai
- ESLint
- Prettier
- Husky
